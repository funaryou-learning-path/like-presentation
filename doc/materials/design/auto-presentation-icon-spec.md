# Auto Presentation — アイコン作成用 仕様書

## アプリ概要

| 項目 | 内容 |
|---|---|
| 正式名称 | Auto Presentation — 勝手にプレゼンしてくれるアプリ |
| 一言コンセプト | **台本を書くだけで、AIがあなたの代わりにプレゼンする** |
| プラットフォーム | Webアプリ（Vite + React, ブラウザで動作） |
| メインユーザー | 人前で話すのが苦手だが、データで訴求したい学生・社会人 |
| 利用シーン | 3分間の授業プレゼン。ダッシュボードで台本と声を選び、ワンクリックで全自動プレゼンを実演する |

## コンセプト・ストーリー

- **課題**: プレゼンは「話す」負担が大きい。暗記・アドリブ・緊張で伝わらない
- **解決**: スライドと台本と合成音声（VOICEVOX）を一体化。AIが喋り、ハイライトが喋っている箇所を光らせ、聴衆は見るだけで理解できる
- **キーワード**: 自動化 / 代行 / ハンズフリー / テレプロンプター / ハイライト / 声

## 主要機能（アイコンに含めたいモチーフの根拠）

| 機能 | モチーフ候補 |
|---|---|
| 合成音声で自動読み上げ（VOICEVOX, Web Speech） | マイク、スピーカー、波形、声紋 |
| 台本（ページごとのセリフ） | 台本、吹き出し、テキスト行 |
| ハイライト同期（喋っているカードが光る） | スポットライト、フォーカス、リング、点灯 |
| AI / 人力モード切替 | ロボット ↔ 人、切替スイッチ、🤖 ↔ 👤 |
| プレゼン（スライド） | スクリーン、スライド、プロジェクター |
| 全自動進行 | 再生ボタン（▶）、自動送り、ループ |

## ビジュアルイメージ

### 世界観
- **科学的でクール、だが親しみやすい**。堅苦しいビジネスではなく、学生の「自販機プレゼン」のようなポップさも持つ
- 「AIが代わりに喋る」ことへの安心感（任せられる）と、少しの遊び心

### カラー
- **ベース**: ダークグリーン `#0d1f0d` / `#1a3a1a`（現行スライドの背景色。お茶・伊藤園のイメージから派生）
- **アクセント**: プライマリグリーン `#4caf50` / `#66bb6a`（ハイライト、再生ボタン）
- **サブ**: ホワイト / 半透明ホワイト（文字、UI）
- アイコンでは **ダーク背景にグリーンの光** が映える構成を推奨

### タイポグラフィ（参考）
- ゴシック系、やや太め。アイコンに文字を入れる場合は `P`（Presentation）や `▶` をモチーフ化

## アイコン要件

### 必須要素（いずれかを組み合わせる）
1. **プレゼン × 音声** を一目で分かること（例: スクリーンの前でスピーカーが喋る、スライドから波形が出る）
2. **自動** であること（再生ボタン、ロボット、AIを示す小さなマーク）
3. **ハイライト** のニュアンス（光る枠、スポットライト）が入ると理想的

### 推奨スタイル
- **シンプルで小サイズでも判別可能**（32pxでも潰れない）
- **1〜2色 + アクセント** で構成。グラデーションは `dark green → primary green` の範囲で
- 角丸（`rounded-2xl`）の背景に、中央にモチーフを配置するスタイルがアプリのUIと親和性が高い
- ダークモード / ライトモードの両方で使えるよう、背景付きと抜きの2パターンを想定

### アイデアスケッチ（叩き台）

```
案A: スクリーン + 波形
  ┌──────────┐
  │ ▭▭▭     │  ← スライド
  │  )))    │  ← 波形（声）
  └──────────┘
  小さな ▶ を右下に

案B: マイク + ハイライトリング
  ○  ← リング（光る）
  🎤 ← マイク
  下に3つのドット（スライド）

案C: ロボットがスライドを指す
  🤖 → ▭  ← AIがプレゼン
  シンプルな線画
```

### NG
- VOICEVOXのキャラクター（ずんだもん等）をそのまま使うことは避ける（権利関係）
- 文字が多すぎる、細かすぎる線は避ける
- 既存のプレゼンアプリ（PowerPoint, Keynote）のアイコンと酷似しないこと
